# Architecture

The repository follows a clean, highly modular Domain-Driven Design (DDD) emphasizing separation of concerns.

## Directory Structure

```text
QuantScale AI/
├── ai/                 # LLM Integration and Prompt Engineering
├── analytics/          # Core Quantitative and Financial Math
├── api/                # FastAPI routing and static frontend serving
├── core/               # Data Transfer Objects (DTOs) and Pydantic Schemas
├── data/               # Market Data ingestion and caching
├── streamlit_app.py    # Main active frontend application
├── main.py             # Pipeline Orchestrator (The QuantScaleSystem facade)
├── config.py           # Environment variables and application settings
└── Dockerfile          # Containerization for Hugging Face Spaces
```

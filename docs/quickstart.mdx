# Local Development

Follow these steps to set up the environment and run the instance on your local machine.

## Prerequisites

- Python 3.9+
- Pip
- Git

## 1. Clone the repository

```bash
git clone https://github.com/AjayKasu1/QuantScaleAI.git
cd QuantScaleAI
```

## 2. Set up a virtual environment

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

## 3. Install dependencies

```bash
pip install -r requirements.txt
```

## 4. Configure Environment Variables

Copy the `.env.example` file to `.env` and add your `BYTEZ_API_KEY`.

```bash
cp .env.example .env
# Edit .env and add your BYTEZ_API_KEY
```

## 5. Run the application

### Streamlit Frontend (Recommended)

```bash
streamlit run streamlit_app.py
```

### FastAPI Backend

```bash
uvicorn api.app:app --reload
```

Your application will be available at `http://localhost:8501`.

# AI Integration

QuantScale AI uses the **Bytez API** (specifically Llama-3-8B-Instruct) for two critical functions:

## 1. Intent Parsing

Translates raw user prompts into structured GICS sector and ticker exclusions.

```python
# ai/ai_reporter.py
def parse_intent(self, user_prompt: str) -> list:
    # Uses low temperature (0.1) for determinism
    content = self._call_bytez(messages, temperature=0.1)
    # Regex extraction to safely isolate JSON list
    match = re.search(r'\[.*\]', content.strip(), re.DOTALL)
    return json.loads(match.group(0))
```

## 2. Narrative Generation

The `generate_report` method takes the finished Attribution Truth Tables and converts them into a professional narrative.
